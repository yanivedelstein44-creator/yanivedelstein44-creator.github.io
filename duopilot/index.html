⬇ הורד את DuoPilot לאנדרואיד

גרסה 1.0.0 · אנדרואיד 11 ומעלה · מתעדכנת לבד

התקנה (פעם אחת)

  1. פותחים את הקובץ שהורד ומאשרים "התקנה ממקור לא ידוע".
  2. פותחים את DuoPilot ← "שירות נגישות" ← הפעל.
  3. אם השירות אפור ("הגדרה מוגבלת"): פרטי האפליקציה ← ⋮ למעלה ← "אפשר הגדרות מוגבלות", וחוזרים לשלב 2.
  4. מאשרים מיקרופון והתראות, ומדביקים מפתח Claude API.
  5. "+ צמד חדש" ← בוחרים מה למעלה ומה למטה.

ברכב (Android Auto)

DuoPilot מופיע באנדרואיד אוטו כשיחת הודעות: האוטו מקריא, ואתה עונה בקול עם פקודה.

פעם אחת: אפליקציית Android Auto ← "גרסה" ← 10 הקשות ← ⋮ ← הגדרות מפתח ← "מקורות לא ידועים".

פרטיות

הצמדים, מיקומי הגלילה ומפתח ה-API נשמרים רק בטלפון. תוכן המסך נשלח ל-Claude רק בזמן שנותנים פקודה.
